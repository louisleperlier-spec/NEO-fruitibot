# NEO-fruitibot

## Navigation du code

Avant de lire un fichier source, consulter `graphify-out/graph.json` pour comprendre la structure du projet. Ne lire que les fichiers strictement nécessaires à la tâche.

Exemple : pour localiser une fonction, chercher son nœud dans `graph.json` (`source_file` + `source_location`) plutôt que de scanner tous les fichiers.
